    ใช้งานครั้งแรก

    1. สร้าง Gemini API Key ที่ aistudio.google.com/apikey (ต้องเปิด Billing เพื่อใช้ Nano Banana Pro ความละเอียด 2K และ Veo 3.1) แล้วใส่ในปุ่ม ⚙️ ตั้งค่า
    2. ใส่ Style Guide ชุดหลักของช่อง → ระบบสร้าง Style Bible ครั้งแรก ตรวจ/แก้ แล้วกด “บันทึก & ล็อก” — จากนี้ทุกเพลงจะใช้ชุดเดิม

    ทุกเพลง (≈ 2 เพลง/สัปดาห์)

    1. ใส่ mp3, เนื้อเพลง, Style Guide (ไฟล์เดิม) → กด ▶ เริ่ม Automation แล้วปล่อยไว้ (ภาพ ~40 ภาพ + คลิป ~40 คลิป ใช้เวลาราว 30–90 นาที แล้วแต่โควตา API)
    2. โหมด Flow: ดาวน์โหลด Flow Pack → ใน Google Flow เลือก Frames to Video ใส่ภาพ scene_XX.png + prompt จาก flow_prompts.txt → ดาวน์โหลดคลิปที่ 1080p (ห้ามเลือก Upscale) → ตั้งชื่อ clip_XX.mp4 → กด “อัปโหลดคลิปหลายไฟล์”
    3. ดาวน์โหลด ZIP → DaVinci Resolve: สร้าง Timeline 1920×1080 ที่ fps ตามตั้งค่า → ลาก mp3 ลง A1 ที่ 01:00:00:00 → File › Import › Timeline › timeline.edl (ชี้โฟลเดอร์ clips) หรือวางตาม editing_guide.txt
    4. ปิดเสียงคลิป หรือลดเหลือ ~-18 dB เพื่อเก็บ SFX → ใส่ Title/End Screen → Export → อัปโหลด YouTube (ตั้ง “Made for Kids”)
    ข้อจำกัดที่ควรรู้: Google Flow ยังไม่มี API สาธารณะ ระบบจึงเรียก Veo 3.1 (โมเดลที่อยู่เบื้องหลัง Flow) ผ่าน Gemini API โดยตรงในโหมดอัตโนมัติ · คลิป Veo มีความยาวขั้นต่ำ 4–8 วินาที ระบบจึงระบุใน Editing Guide ว่าให้ตัดใช้ช่วงไหนของคลิป · API Key ถูกเก็บในเบราว์เซอร์ของคุณเท่านั้นและส่งตรงไปที่ Google
