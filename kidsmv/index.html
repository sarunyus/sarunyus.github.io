Gemini ฟังไฟล์เพลงได้ จึงจับเวลาเนื้อเพลงและแบ่งฉากให้ได้ ใช้แอป Gemini ที่ gemini.google.com แทน API

3คัดลอกคำตอบของ Gemini ทั้งหมด (JSON) มาวางในช่องด้านล่าง แล้วกด “นำเข้า Storyboard”

ขั้นที่ 3ภาพนิ่ง + คลิป ทีละฉาก

ภาพ: กด “📋 Prompt ภาพ” → ไปสร้างใน Google Flow (โหมดสร้างภาพ + ใส่ Style Guide เป็น Ingredients) หรือ Gemini (กด Tools › Create images 🍌 ก่อนวาง Prompt และแนบ Style Guide) → ดาวน์โหลดขนาดใหญ่สุด → ตั้งชื่อ scene_01.png, scene_02.png … → อัปโหลดกลับทีเดียว · ภาพต้อง ≥ 2560×1440
คลิป: กด “🎬 เรนเดอร์คลิปทั้งหมด” สร้างคลิปกล้องเคลื่อนไหว 1920×1080 ในเครื่องฟรี (ย่อภาพลงเท่านั้น ไม่ upscale) — ฉากไหนอยากได้ตัวละครขยับจริง ใช้ “📋 Prompt คลิป” ไปทำใน Flow แล้วอัปโหลดทับ

เคล็ดลับให้ Style ไม่เพี้ยน

  1. สร้างภาพทุกฉากของเพลงเดียวกันในแชต/โปรเจกต์เดียวกัน และแนบภาพ Style Guide ตั้งแต่ข้อความแรก
  2. ใน Google Flow ให้ตั้ง Style Guide / ตัวละครเป็น Ingredients แล้วใช้ซ้ำทุกฉาก
  3. ภาพไหนเพี้ยน ให้สั่งแก้ในแชตเดิม (“ทำให้เหมือน Style Guide มากขึ้น: …”) ดีกว่าสร้างใหม่ในแชตใหม่

ใน DaVinci Resolve

  1. สร้าง Timeline 1920×1080 ที่ fps ตามตั้งค่า (ค่าเริ่มต้น 24) → ลาก mp3 ลง A1 ที่ 01:00:00:00
  2. File › Import › Timeline › เลือก timeline.edl → ชี้ไปที่โฟลเดอร์ clips
  3. ใส่ Title/End screen → Deliver → อัปโหลด YouTube ตั้งค่า “Made for Kids”
ข้อควรรู้: แอปตรวจได้แค่ “จำนวนพิกเซล” ของไฟล์ ตรวจไม่ได้ว่าไฟล์ผ่านการ upscale มาจากเว็บต้นทางหรือไม่ — ตอนดาวน์โหลดจาก Gemini/Flow ให้เลือกขนาดต้นฉบับ (ไม่ใช่ตัวเลือก “Upscaled”) · คลิป 1080p ที่ดาวน์โหลดจาก Flow บางแพ็กเกจเป็นการ upscale จาก 720p ส่วนคลิปที่แอปเรนเดอร์เองเป็นการย่อจากภาพ 2K จึงไม่ upscale แน่นอน
