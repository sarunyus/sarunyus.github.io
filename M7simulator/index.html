1.7พฤติกรรมการชำระเงิน — % ชำระตรงกำหนด แยกตาม Class และช่วงอัตราค่าผ่านทาง

ส่วนที่เหลือจาก 100% คือรายการ "ค้างชำระ" ซึ่งบริษัทฯ ต้องชดเชยรายได้ให้กรมฯ ตามวันในข้อ 1.8 — คอลัมน์ "รายการ M-Flow" คือปริมาณจริงที่ตกอยู่ในช่วงอัตรานั้น คำนวณจากปริมาณจราจรรายคู่ O-D และอัตราค่าผ่านทางของ Class นั้นในหน้า 4

ช่วงค่าผ่านทางรายการ M-Flowสมาชิก — ตรงกำหนดไม่ใช่สมาชิก — ตรงกำหนด
ช่วงอัตราที่ไม่มีรายการของ Class นั้น (แสดงเป็น 0) จะถูกหรี่ลง เพราะไม่มีผลต่อการคำนวณ — ตั้งค่าไว้เผื่อการปรับอัตราในอนาคตได้ · แต่ละ Class เก็บค่าของตัวเองแยกกัน

1.8กำหนดวันชดเชยรายได้ให้กรมฯ

เลือกเองได้อิสระ ไม่ผูกกับข้อ 1.6 — ผ่านทางแล้วครบกี่วัน หากยังไม่จ่าย จึงจะชดเชยรายได้ให้กรมฯ (เฉพาะค่าผ่านทาง ไม่รวมค่าปรับ) เช่น ไม่ใช่สมาชิก กำหนดชำระ 7 วัน แต่ชดเชยเมื่อครบ 23 วัน ก็สามารถทำได้

1.9อัตราการกลับมาชำระ หลังบริษัทฯ ชดเชยแล้ว (%)

% ของรายการที่ชดเชยไปแล้ว ที่ผู้ใช้ทางจะกลับมาชำระ (ค่าผ่านทาง + ค่าปรับ ไม่ว่าจะช้าเพียงใด) — ประวัติที่ผ่านมาเฉลี่ย ~40% ของยอดชดเชย บริษัทฯ เบิกค่าผ่านทางคืนได้ และได้ค่าติดตาม (ข้อ 1.10) สำหรับรายการไม่ใช่สมาชิก · กำหนดแยกตาม Class ได้ เพราะรถแต่ละประเภทมีพฤติกรรมการกลับมาชำระต่างกัน

ช่วงค่าผ่านทาง สมาชิก — ชดเชย / % กลับมาชำระ ไม่ใช่สมาชิก — ชดเชย / % กลับมาชำระ
เฉพาะ "ไม่ใช่สมาชิก" ที่กลับมาชำระเท่านั้นที่เบิกค่าติดตามทวงถาม (ข้อ 1.10) ได้ — สมาชิกที่กลับมาชำระ บริษัทฯ เบิกคืนได้เฉพาะค่าผ่านทาง ไม่ได้ค่าติดตาม
